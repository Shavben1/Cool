# Color Changing Button

A single-page website that showcases a color-changing button. Each click cycles through a curated palette and updates the button's text to reflect the active color theme.

## Getting Started

Open `index.html` in your browser or serve the project locally:

```bash
python -m http.server
```

Then visit `http://localhost:8000`.

## Customization

- Update the color palette in the inline script inside `index.html`.
- Adjust the styles in `styles.css` to tweak the layout or button appearance.
